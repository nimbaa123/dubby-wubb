# Dubby-Wubb
```
bun install
bun run dev        # http://localhost:3000
bun run typecheck && bun run lint && bun run build
```
Core flow (browse packs -> record line by line -> finish -> replay/download WAV/share) works with no env vars.
`.env.example` lists variables for the upcoming Prisma/Auth.js phase.
Demo media: Blender open films; replace `videoUrl` and line timings in `lib/data.ts`.
